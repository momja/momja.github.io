I've been working on a new Open Source project: [Exhibit](https://github.com/momja/Exhibit). It's a personal library for self-contained web tools — the kind generated by [INSERT YOUR AI TOOL HERE].

It is heavily inspired by Simon Willison's [tools](https://tools.simonwillison.net/) aggregator, and Matt Webb's blog post titled ['We need RSS for sharing abundant vibe-coded apps'](https://www.interconnected.org/home/2026/04/29/syndicating-vibes). Simon also recently authored a plugin for datasetted called [datasette-apps](https://simonwillison.net/2026/Jun/18/datasette-apps/) which fills a similar void, although is focused as an integration for datasette rather than a standalone tool.
